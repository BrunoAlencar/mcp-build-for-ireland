## Challenge

Use Irish public data and AI to improve an everyday decision or task. Pick a specific user and place, build the smallest useful version, and show one compelling working demo. Possible themes include comparing transport access, helping communities explore proposed bus links, finding reuse or repair options, and identifying areas for home retrofits.

## Working with data

- Start with [data.gov.ie](https://data.gov.ie/) and check each dataset's geographic coverage, dates, licence, and actual downloadable resource.
- Other starting points named in the guide include [Dublinked](https://data.smartdublin.ie/), the [Central Statistics Office](https://data.cso.ie/), [NTA/TFI](https://developer.nationaltransport.ie/), [EirGrid](https://www.eirgrid.ie/grid/real-time-system-information), [EPA](https://data.epa.ie/), and [Met Éireann](https://www.met.ie/about-us/specialised-services/open-data).
- Fetch a small sample before building around a dataset. Keep a dated sample as a demo fallback, credit its provider, and follow usage limits.
- Show sources and update dates. Label synthetic data and unverified reports. Make assumptions and evidence gaps clear; do not present historical or incomplete data as live or verified.
- Keep API keys on the server and out of shared code. Use only personal data you own, permissioned data, or synthetic examples.

## Build and demo

Agree on a one-sentence description: “We’re helping [who] to [do what] in [place], using [data].” Prove the data works, then build and test the core user flow before adding features or polishing. In the demo, explain who the project helps, show one example, name the data sources, and say what you would improve next.
